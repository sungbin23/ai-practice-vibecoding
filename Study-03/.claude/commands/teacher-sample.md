# 선생님 모드 보조 — 연습용 가상 학생 데이터 만들기

선생님 모드 명령어를 실제 학생 데이터 없이 시험해 볼 수 있도록 **가상 학생 기록 파일**을 만듭니다. 만든 데이터는 실제 성적이 아니므로 수업 자료나 평가에 쓰지 않습니다.

입력값: `$ARGUMENTS`
- 만들 학생 수입니다. 비어 있으면 **8**을 씁니다. 2~30 사이의 정수만 받습니다.
- 사용 예: `/teacher-sample`, `/teacher-sample 20`

## 1. 저장 위치와 덮어쓰기 방지
- 저장 폴더는 `teacher/data/sample/`입니다. 실제 데이터 폴더(`teacher/data/`)와 섞이지 않도록 하위 폴더에 둡니다.
- 그 폴더에 파일이 이미 있으면 덮어쓰지 않고 중단합니다. 지워도 되는지 사용자에게 묻습니다.
- `git check-ignore -q teacher/`로 git 제외를 확인합니다. 제외되지 않으면 중단합니다.

## 2. 생성 규칙
`node` 스크립트로 만듭니다. 스크립트는 scratchpad에 두고 저장소에 남기지 않습니다. 결과가 매번 같도록 시드를 고정한 난수를 씁니다.
- **이름:** `가상학생01.json`처럼 실제 사람으로 오해받지 않는 이름을 씁니다.
- **파일 형식:** 앱의 내보내기 형식 `{ exportedAt, profiles: [1개], records: [...] }`
- **기록 필드:** `quiz-game.js`의 `buildGameRecord`가 만드는 필드와 같습니다.
  - `id`, `profileId`, `name`, `avatar`, `mode`, `category`, `score`, `correct`, `answered`, `total`, `accuracy`, `avgResponseMs`, `maxCombo`, `categoryStats`, `playedAt`
- **학생마다 성향을 다르게 해서** 분석 결과가 골고루 나오게 합니다.
  - 정답률이 높고 안정적인 학생 2명
  - 평균적인 학생 여러 명
  - 정답률이 낮은 학생 1명 → LOW_ACC
  - 최근 성적이 떨어지는 학생 1명 → DROP
  - 한 카테고리만 약한 학생 1명 → WEAK_CAT
  - 빨리 찍는 학생 1명 → RUSH
  - 10일 넘게 기록이 없는 학생 1명 → INACTIVE
  - 학생 수가 적으면 위에서부터 순서대로 줄입니다.
- **수치 조건:**
  - 학생당 3~15게임, 최근 30일 안에 분포시킵니다.
  - 모드는 다섯 가지를 섞습니다. `category` 모드에는 카테고리를 지정합니다.
  - 점수는 앱 규칙(정답 10점 + 빠른 정답 3점 + 힌트 미사용 2점 + 콤보 5점)으로 나올 수 있는 범위 안에서 만듭니다.
  - `correct ≤ answered`이고, `categoryStats`의 합계는 `correct`·`answered`와 같아야 합니다.
