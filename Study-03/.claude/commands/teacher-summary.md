# 선생님 모드 2/5 — 학생별 성적 요약·순위

`teacher/output/merged.json`을 읽어 학생별 성적을 한 표로 요약하고 비교합니다. 결과는 `teacher/output/summary.md`로도 저장합니다. **원본 데이터는 수정하지 않습니다.**

입력값: `$ARGUMENTS`
- 정렬 기준입니다: `accuracy`(기본값, 정답률), `score`(평균 점수), `plays`(플레이 수), `name`(이름)
- 사용 예: `/teacher-summary`, `/teacher-summary score`

## 0. 입력 데이터 준비
- `teacher/output/merged.json`이 없거나 `teacher/data/`의 파일보다 오래되었으면, 먼저 `.claude/commands/teacher-import.md`의 절차를 기본값(기간 `all`)으로 수행합니다.
- import가 실패하면 중단하고 그 오류를 보고합니다.
- 기간은 merged.json의 `period`를 그대로 따르고, 보고서 맨 위에 적습니다.

## 1. 학생별 지표 계산
숫자는 눈으로 세지 말고 `node -e` 스크립트로 계산합니다. 학생마다 다음을 구합니다.

| 지표 | 계산 |
|---|---|
| 플레이 수 | 기록 수 |
| 푼 문제 수 | `answered` 합계 |
| 정답률 | `correct` 합계 ÷ `answered` 합계 (게임별 정답률의 평균이 아님) |
| 평균 점수 | `score` 평균 |
| 최고 점수 | `score` 최댓값과 그 모드 |
| 평균 응답 시간 | `avgResponseMs`를 게임별 `answered`로 가중 평균한 값(초, 소수 1자리) |
| 최장 연속 정답 | `maxCombo` 최댓값 |
| 최근 플레이 | 가장 최근 `playedAt` (YYYY-MM-DD HH:mm) |
| 추세 | 최근 3게임 정답률 평균 − 그 이전 게임 전체의 정답률. 게임이 4개 미만이면 "-" |

## 2. 모드별 점수 비교
- 모드마다 점수 체계가 달라서(예: 60초 타임어택은 푼 문제 수가 들쭉날쭉함) **점수는 같은 모드끼리만 비교**합니다.
- 학생 × 모드 평균 점수 표를 따로 만듭니다. 기록이 없는 칸은 "-"입니다.
- 학생 간 종합 순위는 모드와 상관없는 **정답률**을 기본으로 씁니다.

## 3. 반 전체 요약
- 참여 학생 수, 기간 내 미참여 학생 수, 총 플레이 수
- 반 정답률: 전체 `correct` 합 ÷ 전체 `answered` 합
- 학생 정답률의 중앙값, 최고, 최저
- 평균 응답 시간의 중앙값

## 4. 출력
1. **반 전체 요약**(3번)
2. **학생별 요약 표:** 입력한 정렬 기준으로 정렬합니다.
   - 열: 순위, 학생, 플레이, 푼 문제, 정답률, 평균 점수, 최고 점수(모드), 평균 응답, 최장 연속, 최근 플레이, 추세(▲/▼/-)
   - 미참여 학생은 표 맨 아래에 "미참여"로 표시합니다.
3. **모드별 평균 점수 표**(2번)
4. **한 줄 해석 3개 이내:** 숫자로 뒷받침되는 관찰만 씁니다. 예: "정답률 상위 3명은 모두 평균 응답 시간이 6초 이하". 데이터가 없는 추측은 쓰지 않습니다.

같은 내용을 `teacher/output/summary.md`에 저장합니다. 첫 줄에 `<!-- 작성일: YYYY-MM-DD HH:MM -->` 주석을 넣습니다.
