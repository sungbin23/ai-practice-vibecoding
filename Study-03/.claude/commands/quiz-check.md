# 퀴즈 정답 정확성 검증

`quiz-data.js`의 모든 문제(또는 지정한 범위)에 대해 **정답이 사실인지, 정답이 하나뿐인지, 해설과 맞는지** 검증합니다. **파일은 수정하지 않습니다.** 수정은 사용자가 요청할 때만 합니다.

`/quiz-validate`(최상급 표현 점검), `/quiz-range`(난이도·정답 분포)와 달리, 이 명령은 **정답 내용 자체가 맞는지**를 봅니다.

입력값: `$ARGUMENTS`
- 비어 있으면 전체 문제를 검사합니다.
- 카테고리 이름(예: `과학`), id 범위(예: `41-80`), id 하나(예: `57`)를 줄 수 있습니다.
- `--web`을 붙이면 모든 대상 문제를 웹으로 교차 검증합니다. 없으면 3단계 기준에 해당하는 문제만 웹으로 확인합니다.
- 사용 예: `/quiz-check`, `/quiz-check 지리`, `/quiz-check 41-80 --web`

범위 값이 카테고리 목록에 없고 id 형식도 아니면, 사용법과 카테고리 목록을 보여 주고 끝냅니다.

## 1. 기계 검사 (스크립트, 대상 전체)
`node` 스크립트로 `quiz-data.js`를 실행해 검사합니다. 스크립트는 scratchpad에 둡니다.
- **C1 정답 인덱스:** `correctAnswer`가 0~3의 정수입니다.
- **C2 보기 중복:** 4개 보기 문자열이 서로 다릅니다. 공백과 대소문자를 무시하고 비교합니다.
- **C3 해설 일치:** 정답 보기의 핵심어가 `explanation`에 나옵니다.
  - 괄호나 기호를 뗀 이름으로도 찾습니다. 예: "수소(H)" → "수소"
  - 나오지 않으면 ⚠️입니다. 인덱스가 어긋났을 가능성이 있습니다.
- **C4 오답이 해설에서 정답처럼 서술됨:** 오답 보기 문자열이 해설에서 "~은/는 [질문 대상]입니다"처럼 쓰였는지 봅니다. 의심 문장만 뽑아 사람이 판단하도록 표시합니다.
- **C5 다른 문제와 충돌:** 다른 문제의 해설과 숫자·연도가 다르면 ⚠️입니다. 예: 같은 사건의 연도가 두 문제에서 다름.
- `python validate_quiz.py` 결과도 함께 확인합니다. 구조 오류가 있으면 2단계로 넘어가지 않고 중단합니다.

## 2. 내용 검토 (대상 전체)
문제마다 다음을 판단하고 근거를 한 줄로 적습니다.
- **정답 사실 여부:** 정답 보기가 질문에 대한 사실인가?
- **정답 유일성:** 오답 3개 중 해석에 따라 정답이 될 수 있는 것이 있는가? 예: 같은 업적을 가진 다른 인물, 측정 방식에 따라 바뀌는 순위.
- **해설 정확성:** 해설에 나온 연도·수치·인물이 맞는가?
- **시점 의존성:** 시간이 지나 바뀌었을 수 있는 정보인가? 예: 소장처, 통계, 기록. 시점이 적혀 있는지도 봅니다.

## 3. 웹 교차 검증
- **대상:** `--web`이면 대상 문제 전부입니다. 없으면 다음 중 하나에 해당하는 문제만 검증합니다.
  - 1단계나 2단계에서 ⚠️가 나온 문제
  - 해설에 구체적인 연도나 수치가 있는 문제
  - 시점에 따라 달라지는 정보가 있는 문제
- **방법:**
  - WebSearch로 **서로 다른 출처 2곳 이상**을 확인합니다. 한국사·문화재는 한국민족문화대백과사전·국가유산청을, 과학·지리는 백과사전·공공기관을 우선합니다.
  - 질문 여러 개를 한 번에 검색하지 말고, 사실 하나씩 검색합니다.
- **판정:**
  - ✅ **확인:** 출처 2곳 이상이 일치합니다.
  - ⚠️ **불일치/논란:** 출처끼리 다르거나 학설이 갈립니다. 주류 학설이 무엇인지 적습니다.
  - ❌ **오류:** 정답이나 해설이 출처와 다릅니다.
  - ❓ **미확인:** 출처를 2곳 확보하지 못했습니다. 이 경우 확인했다고 쓰지 않습니다.

## 4. 보고
1. **요약:** 검사 범위와 문제 수, 판정별 건수(✅/⚠️/❌/❓), 웹 검증을 한 문제 수
2. **문제가 있는 항목 표:** ⚠️·❌·❓만 보여 줍니다.

   | id | 카테고리 | 문제(요약) | 현재 정답 | 판정 | 근거 | 수정 제안 |
   |---|---|---|---|---|---|---|

   - 수정 제안은 "원문 → 수정안" 형식입니다. 정답 위치를 바꾸면 `correctAnswer`도 함께 바꿔야 한다고 적습니다.
3. **기계 검사 결과:** C1~C5 항목별로 통과/실패와 해당 id
4. **출처 목록:** 문제 id별로 사이트 이름과 URL
5. **✅ 문제 목록:** id만 나열합니다.
