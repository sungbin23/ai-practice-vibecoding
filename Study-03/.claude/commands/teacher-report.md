# 선생님 모드 5/5 — 한눈에 보는 HTML 대시보드 생성

`teacher/output/merged.json`을 바탕으로 브라우저에서 바로 여는 대시보드 `teacher/output/dashboard.html`을 만듭니다. 이 파일 하나만 있으면 되고, 인터넷 연결이나 외부 라이브러리 없이 동작해야 합니다. **원본 데이터는 수정하지 않습니다.**

입력값: `$ARGUMENTS`
- 대시보드 제목입니다. 비어 있으면 "지식왕 도전 — 선생님 대시보드"를 씁니다(예: `/teacher-report 3학년 2반 상식 퀴즈`).

## 0. 입력 데이터 준비
- `teacher/output/merged.json`이 없거나 `teacher/data/`의 파일보다 오래되었으면, 먼저 `.claude/commands/teacher-import.md` 절차를 기본값으로 수행합니다.
- import가 실패하면 중단하고 그 오류를 보고합니다.
- 지표 정의는 `teacher-summary.md`, `teacher-category.md`, `teacher-alert.md`와 **같은 계산식과 기준값**을 씁니다. 대시보드 숫자와 표 보고서 숫자가 달라지면 안 됩니다.

## 1. 등급 산정 (상위 비율 기준 상대평가)
학생 등급은 절대 점수가 아니라 **반 안에서의 상위 비율**로 정합니다.

| 등급 | 상위 비율 |
|---|---|
| A | 상위 20% 이내 |
| B | 상위 20% 초과 ~ 40% 이내 |
| C | 상위 40% 초과 ~ 70% 이내 |
| D | 하위 30% (상위 70% 초과) |

- **기준 지표:** 기간 내 **정답률**(`correct` 합 ÷ `answered` 합)입니다. 모드마다 점수 체계가 달라 점수로는 학생을 공정하게 비교할 수 없기 때문입니다. teacher-summary의 종합 순위와 같은 기준입니다.
- **평가 대상:** 기간 내 푼 문제가 10개 이상인 학생만 등급을 매깁니다. 대상 학생 수를 N이라고 합니다.
  - 10개 미만인 학생과 미참여 학생은 등급 칸에 "-"를 표시하고 사유를 적습니다(평가 보류: 푼 문제 부족 / 미참여).
  - 이 학생들은 N에도 넣지 않습니다.
- **계산:** `node` 스크립트로 계산합니다.
  1. 대상 학생을 정답률 높은 순으로 정렬합니다.
  2. 순위는 동점자 공동 순위로 매깁니다. 즉, 순위 = 나보다 정답률이 높은 학생 수 + 1입니다.
  3. 상위 비율 = 순위 ÷ N입니다.
  4. 상위 비율이 0.2 이하면 A, 0.4 이하면 B, 0.7 이하면 C, 그 밖은 D입니다.
- **동점자:** 정답률이 같으면 항상 같은 등급입니다. 그래서 등급별 인원이 20/20/30/30% 비율과 정확히 맞지 않을 수 있습니다. 이 점을 범례에 적습니다.
- **인원이 적을 때:** N이 5명 미만이면 상대평가의 의미가 약하다는 경고를 머리글에 표시합니다(등급은 그대로 계산).
- **검증:**
  - 등급별 인원 합계가 N과 같은지 확인합니다.
  - 정답률이 더 높은 학생이 더 낮은 등급을 받은 경우가 없는지 확인합니다.
  - 둘 중 하나라도 어긋나면 대시보드를 만들지 않고 오류를 보고합니다.

## 2. 차트 작성 원칙
- 차트를 만들기 전에 `dataviz` 스킬을 불러 그 절차를 따릅니다.
  - 기본 원칙: 축은 하나만, 색은 의미에 맞게(크기는 한 색조의 진하기), 데이터 표 보기 제공, 라이트·다크 모두 검증
  - 팔레트는 스킬의 `validate_palette.js`로 라이트·다크 두 모드 모두 검사하고, 통과한 색만 씁니다.
- 학생 이름은 반드시 `textContent`로 넣습니다. 파일 이름에서 온 값이라 HTML로 해석되면 안 됩니다.
- 데이터는 `<script>const DATA = …</script>`로 HTML 안에 넣습니다. 집계는 페이지 안의 JS가 합니다.

## 3. 대시보드 구성 (위에서 아래 순서)
1. **머리글:**
   - 제목, 기간, 생성 시각, 학생 수, 총 플레이 수
   - "학생 성적 데이터 — 외부 공유 주의" 문구
   - N이 5명 미만이면 상대평가 경고
2. **요약 타일 5개:**
   - 반 정답률, 참여 학생 수/전체, 평균 응답 시간(중앙값), 🔴 알림 학생 수
   - **등급 분포:** 예) `A 2 · B 2 · C 3 · D 2 · 보류 1`
3. **학생 비교 표:** teacher-summary의 학생별 표와 같은 열에 **등급** 열을 순위 바로 뒤에 추가합니다.
   - 등급은 글자(A/B/C/D)를 꼭 표시하고, 배지 색은 보조로만 씁니다.
     - A→D 순서는 한 색조의 진하기로 나타냅니다. 순서가 있는 값이므로 색조를 여러 개 쓰지 않습니다.
     - 빨강·초록 같은 상태색은 쓰지 않습니다.
   - 등급 열로도 정렬할 수 있습니다.
   - 표 아래 범례: "상대평가(정답률 상위 비율): A 상위 20% · B 40% · C 70% · D 하위 30% · 동점자는 같은 등급 · 푼 문제 10개 미만은 평가 보류"
   - 열 머리를 클릭하면 정렬됩니다(키보드 Enter로도 가능).
   - 이름 검색 입력창을 둡니다.
   - 행을 고르면 아래 5번 상세가 그 학생으로 바뀝니다.
4. **카테고리 히트맵:**
   - 학생 × 카테고리 정답률 표입니다. 칸 색은 한 색조의 진하기로 나타내고, 칸 안에 숫자를 함께 씁니다.
   - 표본 5개 미만은 `*`, 반 평균보다 15%p 이상 낮으면 ⚠️로 표시합니다.
   - 범례(색 단계와 의미)를 둡니다.
5. **선택한 학생 상세:**
   - 등급과 상위 비율(예: "B · 상위 38% (3위/8명)")
   - 게임별 정답률 추이 선 그래프(가로축은 플레이 순서 또는 날짜)
   - 호버하면 일시·모드·점수·정답률 툴팁이 나옵니다.
   - 같은 데이터를 "표로 보기"로도 제공합니다.
   - 그 학생의 알림 코드와 지도 제안을 보여 줍니다.
6. **반 전체 카테고리 정답률 막대 그래프:** 높은 순으로 정렬하고, 막대 끝에 값을 적습니다.
7. **알림 목록:** teacher-alert 결과를 수준별로 보여 줍니다.

## 4. 품질 조건
- `export-report`가 CSV로 내보낼 수 있도록 표를 다음처럼 만듭니다.
  - 표는 `<table>`·`<thead>`·`<tbody>`·`<th>`로 만들고, `data-export` 속성을 붙입니다: 학생 비교 표 `students`, 카테고리 히트맵 `category`, 알림 목록 `alerts`.
  - 알림 목록도 표로 만듭니다. 열은 학생, 수준, 규칙 코드, 근거입니다.
  - 각 표에는 `<caption>`을 둡니다.
- 인쇄 스타일에서는 다크모드여도 흰 배경과 검은 글자로 인쇄되게 합니다.
- 반응형으로 만듭니다. 화면 폭 375px에서 표는 가로로 스크롤되고 나머지는 한 열로 쌓입니다.
- 다크모드는 `prefers-color-scheme`를 따르고, 전환 버튼도 둡니다.
- 모든 조작은 키보드로 할 수 있고, 포커스 테두리가 보여야 합니다.
- 인쇄용 스타일(`@media print`)에서는 버튼과 검색창을 숨기고 표가 잘리지 않게 합니다.

## 5. 검증과 보고
- 다음을 확인합니다.
  - `node`로 HTML 안 스크립트 문법을 점검합니다(스크립트 부분을 뽑아 `node --check`).
  - 가능하면 헤드리스 Chrome으로 데스크톱(1200px)과 모바일(375px, 너비 375px iframe에 넣어서) 화면을 찍어 겹침·잘림을 눈으로 확인합니다.
  - 대시보드의 반 정답률과 학생 수가 merged.json에서 직접 계산한 값과 같은지 비교합니다.
  - 대시보드에 표시된 학생별 등급이 1단계 계산 결과와 같은지 비교합니다.

  - 생성한 파일 경로
