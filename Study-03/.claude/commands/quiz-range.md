# 퀴즈 범위 검토 (난이도·정답 분포)

`quiz-data.js`에서 **시작 번호부터 끝 번호까지**의 문제를 검토하고 난이도와 정답 분포를 확인합니다. **파일은 수정하지 않습니다.**

입력값: `$ARGUMENTS`

## 1. 범위 정하기
- 위 입력값을 공백으로 나눠 **첫 번째 값을 시작 번호, 두 번째 값을 끝 번호**로 씁니다.
- 문제 번호는 각 문제의 `id` 값입니다. 배열 순서가 아닙니다.
- 사용 예: `/quiz-range 1 10` → id 1~10번 검토
- 인자 처리:
  - 두 값이 모두 정수이면 그 범위를 검토합니다. 시작 번호가 끝 번호보다 크면 두 값을 바꿔서 검토하고, 바꿨다고 알려 줍니다.
  - 끝 번호가 없으면 시작 번호의 문제 하나만 검토합니다.
  - 시작 번호가 없거나 정수가 아니면 검토하지 않습니다. 사용법과 현재 id 범위(가장 작은 id~가장 큰 id)를 보여 주고 끝냅니다.
  - 범위 안에 없는 id가 있으면 그 번호를 "없는 번호"로 따로 적습니다.
- 결과 맨 위에 검토 범위와 실제로 찾은 문제 수를 적습니다(예: "범위: 11~20번 (10문제)").

## 2. 문제별 목록
`quiz-data.js`를 읽어 범위 안 문제마다 다음 내용을 정리합니다. `correctAnswer`는 0부터 시작하는 인덱스이므로, 보기 번호는 **인덱스 + 1**(1~4번)로 표시합니다.

| id | 카테고리 | 난이도 | 문제(요약) | 정답 보기 번호 | 정답 내용 | 난이도 적절성 |
|---|---|---|---|---|---|---|

- 난이도 적절성: 문제 내용을 보고 표시된 난이도(`easy`/`medium`/`hard`)가 알맞은지 판단합니다.
  - 알맞으면 ✅, 다른 난이도가 더 맞아 보이면 ⚠️와 함께 이유와 권장 난이도를 적습니다.
  - 판단 기준: easy는 초·중등 교과 수준의 기본 상식, medium은 고등 교과나 교양 수준, hard는 세부 연도·인물·사건까지 알아야 하는 수준입니다.

## 3. 분포 요약
범위 안 문제만으로 계산합니다.

**카테고리 분포**: 범위 안에 있는 카테고리별 문제 수를 적습니다.

## 4. 치우침 점검
아래 조건에 걸리면 ⚠️로 알려 줍니다. 걸리는 조건이 없으면 "치우침 없음"이라고 적습니다.
- **정답 위치:** 한 보기 번호가 40%를 넘거나, 범위가 8문제 이상인데 한 번도 정답이 아닌 보기 번호가 있을 때
- **정답 연속:** id 순서로 같은 보기 번호가 3번 이상 연속으로 정답일 때(해당 id를 적음)
- **난이도:** 한 난이도가 70%를 넘거나, 범위가 8문제 이상인데 없는 난이도가 있을 때
- **난이도 적절성:** 2번 표에서 ⚠️로 표시한 문제가 있을 때

⚠️ 항목마다 개선안을 제안합니다.
- 정답 위치: 어느 문제의 보기 순서를 어떻게 바꾸면 분포가 고르게 되는지 적습니다. 보기를 바꾸면 `correctAnswer`도 같이 바꿔야 한다는 점도 적습니다.
- 난이도: 어느 문제의 난이도를 무엇으로 바꾸면 좋은지 적습니다.

마지막 줄: `python validate_quiz.py` 구조 검사 결과(통과/실패) 한 줄. 이 스크립트는 항상 전체 파일을 검사한다는 점도 함께 적습니다.

수정은 사용자가 요청할 때만 합니다.
