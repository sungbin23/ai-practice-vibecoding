# 👑 지식왕 도전 Ultimate (Knowledge King Challenge)

Vanilla JavaScript로 개발된 웹 기반 상식 퀴즈 게임입니다. 생성형 AI 콘텐츠 작성 시 발생할 수 있는 **할루시네이션(Hallucination, 정보 오류)을 방지하는 교차 검증 가이드라인**을 적용하여 구현되었습니다.

## 🌟 주요 기능 및 특징
- **4개 카테고리 × 20문제 = 총 80문제 (4지선다)**: 한국사, 과학, 지리, 예술과 문화
  - 문제 데이터 구조: `{ id, category, difficulty, question, options, correctAnswer, explanation }` (`correctAnswer`는 정답 보기의 0부터 시작하는 인덱스)
- **즉시 피드백**: 보기를 고르는 즉시 정답/오답 표시와 해설 제공, 결과 화면에 총점과 정답 개수 표시
- **5가지 게임 모드**:
  - 🟢 **전체 도전**: 40문제, 시간 제한 없이 여유롭게 풀기
  - 📚 **카테고리별 도전**: 고른 카테고리의 10문제
  - ⚡ **스피드 퀴즈**: 20문제, 문제당 15초 제한
  - 💀 **서바이벌**: 오답 시 즉시 게임 오버
  - ⏱️ **60초 타임어택**: 60초 동안 최대한 많은 점수 획득
- **점수 체계**: 정답 기본 10점 + 10초 안에 맞히면 +3 + 힌트 미사용 +2 + 2연속 이상 정답 콤보 +5
- **힌트·일시정지·타이머**: 힌트는 오답 2개 제거(게임당 3회), ⏸ 버튼/Esc로 일시정지(탭 전환 시 자동), 모든 모드에서 문제별 경과 시간 표시
- **결과 분석**: 총점, 정답률, 카테고리별 정답 수, 평균 응답 시간, 최장 연속 정답
- **몰입감 넘치는 UX/UI**:
  - **Web Audio API**: 외부 음원 파일 없이 내장 신디사이저 기반 효과음 출력
  - **Canvas Confetti Engine**: 정답 및 최고 기록 달성 시 폭죽 연출
  - **오답 화면 흔들림 애니메이션**
- **기록 저장 기능**: 브라우저 `localStorage`에 게임 결과(일시·모드·점수·정답률·카테고리별 정답 등)를 저장하고, 역대 최고 점수와 프로필별 개인 최고 기록 표시
- **리더보드**: 일간·주간(월요일 시작)·전체·카테고리별, 프로필별 최고 점수 상위 10명
- **통계 대시보드**: 플레이 횟수, 모드별 횟수, 카테고리별 정답률, 최근 30게임 점수 추이 그래프(표로 보기 제공)
- **프로필**: 상단 [프로필]에서 이름·아바타 편집, 여러 프로필 만들기·전환
- **접근성·편의**: 반응형(모바일), 다크모드(시스템 설정 자동 반영 + 수동 전환), 키보드 조작(1~4 보기, H 힌트, Enter 다음, Esc/P 일시정지), 결과 클립보드 복사
- **자동화 검증 스크립트 제공**: `validate_quiz.py`를 실행하여 데이터 구조(필수 키, 4지선다, 정답 범위, 카테고리별 20문제·총 80문제 이상)를 검사하고 모호한 최상급 표현을 자동 탐지

## 🛡️ AI 할루시네이션 방지 가이드라인 (Data Integrity)
본 프로젝트의 모든 퀴즈 데이터는 다음 기준을 엄격히 준수합니다.
1. **정답 유일성**: 유일한 정답만 존재하도록 질문 구조화
2. **최상급 표현의 기준 명시**: '가장', '최초' 등의 표현 사용 시 측정 기준(예: 2024년 기준, 전통적 기준) 명시
3. **교차 검증**: 다수의 신뢰할 수 있는 출처를 근거로 데이터 구성

3. 데이터 검증을 진행하려면 터미널에서 다음 명령어를 실행합니다.

   python validate_quiz.py
