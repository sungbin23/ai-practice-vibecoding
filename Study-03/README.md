# Study-03 — 상식 퀴즈 게임 「지식왕 도전 Ultimate」

한국사·과학·지리·예술과 문화 4개 카테고리의 4지선다 상식 퀴즈 게임입니다. 다른 AI로 먼저 만든 게임(4가지 모드, 효과음, 폭죽 효과)을 유지하면서 교재 1~3단계 요구사항을 채웠습니다. AI가 만든 문제의 오류(할루시네이션)를 줄이기 위해 **퀴즈 문제 교차 검증 가이드라인**을 메모리에 넣고, 문제 점검·추가·통계용 **커스텀 명령어**를 만든 것이 이 실습의 핵심입니다.

## 주요 기능
- **문제 80개**: 카테고리별 20문제, 데이터 구조 `{ id, category, difficulty, question, options, correctAnswer, explanation }`
- **5가지 모드**: 전체 도전(40문제), 카테고리별 도전(10문제), 스피드(20문제, 문제당 15초), 서바이벌(한 번 틀리면 끝), 60초 타임어택
- **점수**: 정답 10점 + 10초 안에 맞히면 +3 + 힌트 안 쓰면 +2 + 연속 정답 콤보 +5
- **힌트·일시정지**: 오답 2개 제거 힌트(게임당 3회), 일시정지, 문제별 타이머
- **결과 분석**: 총점, 정답률, 카테고리별 정답 수, 평균 응답 시간, 최장 연속 정답
- **기록**: `localStorage`에 게임 기록 저장, 개인 최고 기록, 리더보드(일간·주간·전체·카테고리별 상위 10명), 통계 대시보드(점수 추이 그래프), 프로필 편집
- **편의**: 반응형, 다크 모드, 키보드 조작(1~4 보기, H 힌트, Enter 다음, Esc 일시정지), 결과 클립보드 공유, Web Audio 효과음, 폭죽 효과

## 폴더 구조
```
Study-03/
├── CLAUDE.md            # 구조, 게임 규칙 수치, 퀴즈 작성 규칙
├── index.html           # 화면 구성(시작·퀴즈·결과 화면, 리더보드·통계·프로필 대화상자)
├── styles.css           # 스타일(라이트/다크 테마 CSS 변수)
├── quiz-data.js         # 문제 80개 데이터
├── quiz-records.js      # localStorage 기록·프로필·리더보드·통계 집계
├── quiz-game.js         # 게임 진행(모드, 점수, 힌트, 타이머, 결과 분석, 효과음, 폭죽)
├── quiz-ui.js           # 상단 바, 다크 모드, 리더보드·통계·프로필 화면
├── validate_quiz.py     # 문제 데이터 구조 검사 + 최상급 표현 경고
├── .gitignore           # 선생님 모드 학생 데이터(teacher/) 제외
└── .claude/commands/    # 커스텀 명령어(아래 표)
```

### 커스텀 명령어 (`.claude/commands/`)
| 명령어 | 하는 일 |
|---|---|
| `/quiz-validate [카테고리]` | '가장·최초·최대' 같은 최상급 표현을 찾아 명시할 기준을 알려 줌(`$ARGUMENTS`) |
| `/quiz-range 시작 끝` | 지정 범위 문제의 난이도·정답 분포 검토(`$1`, `$2`) |
| `/quiz-add 카테고리 난이도` | 가이드라인에 맞춰 새 문제 추가(`$1`, `$2`) |
| `/quiz-check` | 모든 문제 정답이 사실인지, 정답이 하나뿐인지 검증 |
| `/quiz-stats` | 게임 통계 기능 분석·검증·확장 |
| `/quiz-leaderboard` | 순위 규칙 확인·검증·변경 |
| `/quiz-daily [개수]` | 구조 파악 → 분포 확인 → 부족한 부분 파악 → 중복 체크 → 추가 → 형식 검증 → 백업 → 보고(단계별 실패 시 중단) |
| `/teacher-sample` | 선생님 모드 연습용 가상 학생 데이터 생성 |
| `/teacher-import` | 학생 기록 수집·검증·병합 |
| `/teacher-summary` | 학생별 성적 요약·순위 |
| `/teacher-category` | 카테고리별 학생 비교 |
| `/teacher-alert` | 도움이 필요한 학생 찾기 |
| `/teacher-report` | HTML 대시보드 생성(상대평가 등급) |
| `/export-report` | 대시보드를 CSV·PDF로 저장 |
| `/teacher-dashboard` | 위 선생님 모드 명령어를 순서대로 모두 실행하는 통합 명령어 |

선생님 모드가 만드는 학생 데이터와 보고서(`teacher/`)는 개인정보로 보고 `.gitignore`로 커밋에서 뺐습니다.

## 실행 방법
설치할 것이 없습니다. `index.html`을 브라우저에서 열면 됩니다. API 키도 필요 없습니다.

문제 데이터 검사(필수 키, 보기 4개, 정답 범위, 중복, 카테고리별 20문제 이상)는 Python으로 실행합니다.
```powershell
python validate_quiz.py
```

커스텀 명령어는 이 폴더에서 `claude`를 실행한 뒤 `/quiz-validate 한국사`처럼 입력합니다. 명령어 파일을 새로 만들었다면 클로드 코드를 다시 시작해야 인식됩니다.

## 사용한 클로드 코드 기능
- **`/init`**: 기존 코드를 분석해 `CLAUDE.md`를 만들었습니다.
- **`/memory`**: 프로젝트 메모리를 열어 퀴즈 문제 교차 검증 가이드라인(정답 유일성, 최상급 표현 기준, 시간·범위 명시, 교차 검증)을 저장했습니다. 이 가이드라인은 저장소 루트 `CLAUDE.md`에 들어 있습니다.
- **가이드라인 기반 점검**: 저장한 가이드라인을 기준으로 기존 문제를 점검하고, 기준이 빠진 최상급 표현 등을 고쳤습니다. 검사는 `validate_quiz.py`로 다시 확인합니다.
- **커스텀 명령어**: `.claude/commands/`에 명령어 15개를 만들었습니다. `$ARGUMENTS`, `$1`·`$2` 인자를 쓰고, 여러 명령어를 이어서 실행(체이닝)하거나 `/quiz-daily`, `/teacher-dashboard`처럼 하나로 묶은 통합 명령어도 만들었습니다.
