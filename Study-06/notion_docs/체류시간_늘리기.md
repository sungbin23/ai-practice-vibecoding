# 웹 포트폴리오 방문자 체류 시간 2배 늘리기

## 목표
방문자의 평균 체류 시간을 지금의 2배로 늘립니다.

## 아이디어

### 1. 첫 화면에서 붙잡기
- 첫 화면에 한 줄 자기소개와 대표 작업 하나를 크게 보여 줍니다.
- "프로젝트 보기" 같은 눈에 띄는 버튼을 둡니다.
- 로딩이 느리면 바로 나가므로 이미지를 압축하고 지연 로딩을 씁니다.

### 2. 프로젝트를 이야기로 보여 주기
- 결과 화면만 두지 않고 문제 → 고민 → 해결 → 결과 순서의 사례 글로 씁니다.
- 작업 과정 사진, 전후 비교, 짧은 데모 영상이나 GIF를 넣습니다.
- 직접 눌러 볼 수 있는 라이브 데모 링크를 붙입니다.

### 3. 다음 볼거리 이어 주기
- 프로젝트 글 끝에 "다음 프로젝트" 버튼과 관련 작업 카드를 둡니다.
- 기술·분야별 태그 필터로 관심 있는 작업만 골라 보게 합니다.

### 4. 상호작용 요소 넣기
- 마우스를 올리면 움직이는 카드, 스크롤에 맞춰 나타나는 애니메이션을 넣습니다(과하지 않게).
- 간단한 미니 게임이나 인터랙티브 소개 같은 재미 요소를 둡니다.

### 5. 읽을거리 늘리기
- 개발 일지나 회고 같은 블로그 글을 함께 둡니다.
- 글마다 예상 읽기 시간을 표시합니다.

### 6. 모바일과 가독성
- 모바일에서도 깨지지 않게 반응형으로 만듭니다.
- 글자 크기와 줄 간격을 넉넉히 하고, 한 화면에 정보를 너무 많이 넣지 않습니다.

### 7. 측정하기
- Google Analytics 같은 도구로 평균 체류 시간과 이탈률을 봅니다.
- 바꾼 뒤 수치가 오르는지 확인하고 효과 없는 것은 되돌립니다.

## 바로 해 볼 일
1. 이미지 최적화로 첫 화면 로딩 속도 줄이기
2. 대표 프로젝트 하나를 사례 글 형식으로 다시 쓰기
3. 모든 프로젝트 글 끝에 "다음 프로젝트" 버튼 달기
4. 분석 도구를 설치해 지금 체류 시간 기록해 두기
