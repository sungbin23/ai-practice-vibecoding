# Study-02 — 할 일 관리 앱 (My Tasks)

서버 없이 브라우저 `localStorage`에 데이터를 저장하는 할 일 관리 웹 앱입니다. 다른 AI로 먼저 만든 앱을 교재의 Step 1~5 요구사항에 맞춰 점검하고, 빠진 기능을 클로드 코드로 채웠습니다. 모바일용 기본 버전과 데스크톱 전체 화면용 `web_version` 두 가지 화면이 있습니다.

## 주요 기능
- **기본**: 할 일 추가(Enter/버튼), 삭제, 체크로 완료 표시(취소선), 새로고침해도 유지
- **카테고리**: 업무·개인·공부 색상 태그와 필터, 완료 항목은 자동으로 아래로 정렬
- **키워드 자동 분류**: 입력한 문장 속 키워드를 보고 카테고리를 자동으로 골라 줌(직접 고르면 자동 분류 멈춤)
- **진행률 대시보드**: 전체·카테고리별 완료율 막대, 오늘 추가한 개수
- **편집**: 더블클릭 인라인 수정(Enter 저장, Esc 취소), 드래그 앤 드롭 순서 변경, 정렬(생성일·카테고리·완료 상태)
- **편의**: 다크 모드, 실시간 검색, 완료 항목 일괄 삭제, 삭제 실행 취소(5초, Ctrl+Z), JSON 내보내기/가져오기
- **단축키**: `Alt+N` 입력창, `Alt+1~4` 필터, `Alt+D` 다크 모드

## 폴더 구조
```
Study-02/
├── CLAUDE.md                  # 구조·동작 방식·카테고리 수정 시 함께 고칠 곳
├── index.html                 # 기본(모바일 최적화) 화면
├── style.css                  # 기본 화면 스타일 + 다크 모드
├── script.js                  # 앱 전체 로직(상태, 저장, 렌더링, 자동 분류 등)
├── web_version/               # 데스크톱 전체 화면 버전
│   ├── index.html             # 상단 바 + 왼쪽 사이드바 + 메인 목록 레이아웃
│   ├── style.css              # 데스크톱 레이아웃 스타일
│   └── script.js              # 루트 script.js와 같은 로직의 복사본
└── todo-app-conversation.txt  # /export로 내보낸 클로드 코드 대화 기록
```

## 실행 방법
설치할 것이 없습니다. `index.html`(모바일 화면) 또는 `web_version/index.html`(데스크톱 화면)을 브라우저에서 열면 됩니다. API 키도 필요 없습니다.

저장된 데이터를 지우려면 브라우저 개발자 도구(F12) 콘솔에서 `localStorage.clear()`를 실행합니다.

## 사용한 클로드 코드 기능
- **`/init`**: 기존 코드를 분석해 `CLAUDE.md`를 만들었습니다.
- **요구사항 점검**: 교재 Step 1~5 기준으로 기능별 구현됨/부분 구현/없음 표를 받고, 빠진 기능만 추가했습니다.
- **기능 추가 요청**: 키워드 기반 자동 카테고리 분류를 추가했습니다.
- **새 폴더로 디자인 변경**: 데스크톱 전체 화면에 맞춘 디자인을 `web_version` 폴더에 따로 만들었습니다.
- **`@` 참조**: `@script.js`로 다크 모드 관련 함수를 찾아 설명받고, `@web_version`으로 폴더 전체를 분석해 데스크톱 최적화 여부를 확인했습니다.
- **`/export`**: 대화 내용을 `todo-app-conversation.txt`로 내보냈습니다. 위 과정이 모두 이 파일에 남아 있습니다.
